# Audit modules configuration

## Properties

- <a id="properties/audit"></a>**`audit`** *(object)*: Cannot contain additional properties.
  - <a id="properties/audit/properties/enabled"></a>**`enabled`** *(boolean)*: Default: `true`.
  - <a id="properties/audit/properties/snyk"></a>**`snyk`** *(object)*: Cannot contain additional properties.
    - <a id="properties/audit/properties/snyk/properties/enabled"></a>**`enabled`** *(boolean)*: Enable Snyk audit. Default: `true`.
    - <a id="properties/audit/properties/snyk/properties/auto-fix"></a>**`auto-fix`** *(boolean)*: Apply the fixes and open a pull request with them, when false the vulnerabilities are only reported. Can be set per branch in the .github/ghci.yaml file of the stabilization branch. Disabled by default, the Python and npm dependency fixes are done by the Trivy dependencies audit. Default: `false`.
    - <a id="properties/audit/properties/snyk/properties/files-no-install"></a>**`files-no-install`** *(array)*: Dependency files that will not be installed. Default: `[]`.
      - <a id="properties/audit/properties/snyk/properties/files-no-install/items"></a>**Items** *(string)*
    - <a id="properties/audit/properties/snyk/properties/excluded-files"></a>**`excluded-files`** *(array)*: List of regex patterns for file names to exclude from the transversal dashboard and security advisories. Default: `[]`.
      - <a id="properties/audit/properties/snyk/properties/excluded-files/items"></a>**Items** *(string)*
    - <a id="properties/audit/properties/snyk/properties/dashboard-severity-threshold"></a>**`dashboard-severity-threshold`** *(string)*: Minimum severity level to display on the transversal dashboard (low, medium, high, critical). Must be one of: "low", "medium", "high", or "critical". Default: `"medium"`.
    - <a id="properties/audit/properties/snyk/properties/pip-install-arguments"></a>**`pip-install-arguments`** *(array)*: Arguments to pass to pip install. Default: `[]`.
      - <a id="properties/audit/properties/snyk/properties/pip-install-arguments/items"></a>**Items** *(string)*
    - <a id="properties/audit/properties/snyk/properties/pipenv-sync-arguments"></a>**`pipenv-sync-arguments`** *(array)*: Arguments to pass to pipenv sync. Default: `[]`.
      - <a id="properties/audit/properties/snyk/properties/pipenv-sync-arguments/items"></a>**Items** *(string)*
    - <a id="properties/audit/properties/snyk/properties/poetry-install-arguments"></a>**`poetry-install-arguments`** *(array)*: Arguments to pass to pip install. Default: `[]`.
      - <a id="properties/audit/properties/snyk/properties/poetry-install-arguments/items"></a>**Items** *(string)*
    - <a id="properties/audit/properties/snyk/properties/java-path-for-gradle"></a>**`java-path-for-gradle`** *(object)*: Path to the directory that contains Java executable to use for the Gradle minor version. Can contain additional properties. Default: `{}`.
      - <a id="properties/audit/properties/snyk/properties/java-path-for-gradle/additionalProperties"></a>**Additional properties** *(string)*
    - <a id="properties/audit/properties/snyk/properties/monitor-arguments"></a>**`monitor-arguments`** *(array)*: Arguments to pass to Snyk monitor. Default: `["--all-projects"]`.
      - <a id="properties/audit/properties/snyk/properties/monitor-arguments/items"></a>**Items** *(string)*
    - <a id="properties/audit/properties/snyk/properties/test-arguments"></a>**`test-arguments`** *(array)*: Arguments to pass to Snyk test. Default: `["--all-projects", "--severity-threshold=medium"]`.
      - <a id="properties/audit/properties/snyk/properties/test-arguments/items"></a>**Items** *(string)*
    - <a id="properties/audit/properties/snyk/properties/fix-arguments"></a>**`fix-arguments`** *(array)*: Arguments to pass to Snyk fix. Default: `["--all-projects"]`.
      - <a id="properties/audit/properties/snyk/properties/fix-arguments/items"></a>**Items** *(string)*
    - <a id="properties/audit/properties/snyk/properties/monitor"></a>**`monitor`** *(object)*: Cannot contain additional properties.
      - <a id="properties/audit/properties/snyk/properties/monitor/properties/project-environment"></a>**`project-environment`** *(array)*: Set the project environment project attribute. To clear the project environment set empty array.
For more information see Project attributes https://docs.snyk.io/getting-started/introduction-to-snyk-projects/view-project-information/project-attributes.
        - <a id="properties/audit/properties/snyk/properties/monitor/properties/project-environment/items"></a>**Items** *(string)*: Must be one of: "frontend", "backend", "internal", "external", "mobile", "saas", "onprem", "hosted", or "distributed".
      - <a id="properties/audit/properties/snyk/properties/monitor/properties/project-lifecycle"></a>**`project-lifecycle`** *(array)*: Set the project lifecycle project attribute. To clear the project lifecycle set empty array.
For more information see Project attributes https://docs.snyk.io/snyk-admin/snyk-projects/project-tags.
        - <a id="properties/audit/properties/snyk/properties/monitor/properties/project-lifecycle/items"></a>**Items** *(string)*: Must be one of: "production", "development", or "sandbox".
      - <a id="properties/audit/properties/snyk/properties/monitor/properties/project-business-criticality"></a>**`project-business-criticality`** *(array)*: Set the project business criticality project attribute. To clear the project business criticality set empty array.
For more information see Project attributes https://docs.snyk.io/snyk-admin/snyk-projects/project-tags.
        - <a id="properties/audit/properties/snyk/properties/monitor/properties/project-business-criticality/items"></a>**Items** *(string)*: Must be one of: "critical", "high", "medium", or "low".
      - <a id="properties/audit/properties/snyk/properties/monitor/properties/project-tags"></a>**`project-tags`** *(object)*: Set the project tags to one or more values.
To clear the project tags set empty dictionary. Can contain additional properties.

  - <a id="properties/audit/properties/dpkg"></a>**`dpkg`** *(object)*: Cannot contain additional properties.

    - <a id="properties/audit/properties/renovate/properties/enabled"></a>**`enabled`** *(boolean)*: Enable Renovate audit. Default: `true`.
  - <a id="properties/audit/properties/trivy"></a>**`trivy`** *(object)*: Trivy scans: the container images of the ArgoCD applications, the Python, npm and Gradle dependencies of the branches, and the pull requests. Cannot contain additional properties.
    - <a id="properties/audit/properties/trivy/properties/image"></a>**`image`** *(object)*: Scan the container images used by the ArgoCD applications with Trivy. Cannot contain additional properties.
      - <a id="properties/audit/properties/trivy/properties/image/properties/enabled"></a>**`enabled`** *(boolean)*: Enable the container images audit, only applied to repositories that have an `apps/` directory of Helm applications. Default: `true`.
      - <a id="properties/audit/properties/trivy/properties/image/properties/apps-root"></a>**`apps-root`** *(string)*: The directory that contains the ArgoCD applications, `<apps-root>/<environment>/[<client>/]<app>/Chart.yaml`. Default: `"apps"`.
      - <a id="properties/audit/properties/trivy/properties/image/properties/environments"></a>**`environments`** *(array)*: The environment sub-directories of `apps-root` that are scanned, matching the directories deployed by ArgoCD. Default: `["int", "prod"]`.
        - <a id="properties/audit/properties/trivy/properties/image/properties/environments/items"></a>**Items** *(string)*
      - <a id="properties/audit/properties/trivy/properties/image/properties/app-structure"></a>**`app-structure`** *(string)*: `auto` detects the layout, `single` for `<apps-root>/<environment>/<app>/`, `two-level` for `<apps-root>/<environment>/<client>/<app>/`. Must be one of: "auto", "single", or "two-level". Default: `"auto"`.
      - <a id="properties/audit/properties/trivy/properties/image/properties/severity-threshold"></a>**`severity-threshold`** *(string)*: Minimum severity level of the vulnerabilities to report and display (low, medium, high, critical). Must be one of: "low", "medium", "high", or "critical". Default: `"critical"`.
      - <a id="properties/audit/properties/trivy/properties/image/properties/ignore-unfixed"></a>**`ignore-unfixed`** *(boolean)*: Do not report the vulnerabilities that have no fix yet. Default: `false`.
      - <a id="properties/audit/properties/trivy/properties/image/properties/excluded-apps"></a>**`excluded-apps`** *(array)*: List of regex patterns for application directory paths to exclude from the images scan. Default: `[]`.
        - <a id="properties/audit/properties/trivy/properties/image/properties/excluded-apps/items"></a>**Items** *(string)*
    - <a id="properties/audit/properties/trivy/properties/pull-request"></a>**`pull-request`** *(object)*: Scan the pull request code with Trivy, reported as an action required check. Cannot contain additional properties.
      - <a id="properties/audit/properties/trivy/properties/pull-request/properties/enabled"></a>**`enabled`** *(boolean)*: Scan the pull requests with Trivy. Default: `true`.
      - <a id="properties/audit/properties/trivy/properties/pull-request/properties/scanners"></a>**`scanners`** *(array)*: The Trivy scanners run on the pull request with the `trivy fs` command. Default: `["secret", "misconfig"]`.
        - <a id="properties/audit/properties/trivy/properties/pull-request/properties/scanners/items"></a>**Items** *(string)*
      - <a id="properties/audit/properties/trivy/properties/pull-request/properties/severity"></a>**`severity`** *(string)*: The minimum severities reported by the Trivy scans, as a comma separated list. Default: `"HIGH,CRITICAL"`.
      - <a id="properties/audit/properties/trivy/properties/pull-request/properties/ignore-file"></a>**`ignore-file`** *(string)*: The path of the Trivy ignore file in the repository, the `--ignorefile` argument is added only if the file exists. Default: `".github/.trivyignore.yaml"`.
      - <a id="properties/audit/properties/trivy/properties/pull-request/properties/config-targets"></a>**`config-targets`** *(array)*: The files scanned with the `trivy config` command, the command is run only for the files that exist in the repository. Default: `["Dockerfile"]`.
        - <a id="properties/audit/properties/trivy/properties/pull-request/properties/config-targets/items"></a>**Items** *(string)*
    - <a id="properties/audit/properties/trivy/properties/filesystem"></a>**`filesystem`** *(object)*: Scan the Python, npm and Gradle dependencies (poetry.lock, requirements files, package-lock.json and gradle.lockfile) with Trivy and fix the vulnerabilities. Cannot contain additional properties.
      - <a id="properties/audit/properties/trivy/properties/filesystem/properties/enabled"></a>**`enabled`** *(boolean)*: Enable the Trivy dependencies audit, only applied to branches that have a `poetry.lock`, a requirements file, a `package-lock.json` or a Gradle project. Default: `true`.
      - <a id="properties/audit/properties/trivy/properties/filesystem/properties/auto-fix"></a>**`auto-fix`** *(boolean)*: Apply the fixes and open a pull request with them, when false the vulnerabilities are only reported. Can be set per branch in the .github/ghci.yaml file of the stabilization branch. Default: `true`.
      - <a id="properties/audit/properties/trivy/properties/filesystem/properties/fix-severity-threshold"></a>**`fix-severity-threshold`** *(string)*: Minimum severity level of the vulnerabilities to fix: vulnerabilities below this threshold are reported and ignored, not pinned, to limit the churn of transitive fixes (low, medium, high, critical). Must be one of: "low", "medium", "high", or "critical". Default: `"high"`.
      - <a id="properties/audit/properties/trivy/properties/filesystem/properties/dashboard-severity-threshold"></a>**`dashboard-severity-threshold`** *(string)*: Minimum severity level to display on the transversal dashboard, the vulnerabilities below are reported on the output page in a collapsed section (low, medium, high, critical). Must be one of: "low", "medium", "high", or "critical". Default: `"high"`.
      - <a id="properties/audit/properties/trivy/properties/filesystem/properties/excluded-files"></a>**`excluded-files`** *(array)*: List of regex patterns for file names to exclude from the transversal dashboard. Default: `[]`.
        - <a id="properties/audit/properties/trivy/properties/filesystem/properties/excluded-files/items"></a>**Items** *(string)*
      - <a id="properties/audit/properties/trivy/properties/filesystem/properties/files-no-fix"></a>**`files-no-fix`** *(array)*: Dependency files in which the fixes are not applied and not validated, the vulnerabilities they report are only reported. Default: `[]`.
        - <a id="properties/audit/properties/trivy/properties/filesystem/properties/files-no-fix/items"></a>**Items** *(string)*
      - <a id="properties/audit/properties/trivy/properties/filesystem/properties/pip-install-arguments"></a>**`pip-install-arguments`** *(array)*: Arguments to pass to `pip install --dry-run` when validating the fixed requirements files. Default: `[]`.
        - <a id="properties/audit/properties/trivy/properties/filesystem/properties/pip-install-arguments/items"></a>**Items** *(string)*
  - <a id="properties/audit/properties/version-mapping"></a>**`version-mapping`** *(object)*: Mapping of version to the branch name. Can contain additional properties. Default: `{}`.
    - <a id="properties/audit/properties/version-mapping/additionalProperties"></a>**Additional properties** *(string)*
  - <a id="properties/audit/properties/pre-commit"></a>**`pre-commit`** *(object)*: Cannot contain additional properties.

    - <a id="properties/audit/properties/pre-commit/properties/skip-hooks"></a>**`skip-hooks`** *(array)*: List of pre-commit hooks to skip. Default: `[]`.
